# Look and feel

Make TypstDrive look like your own in **Site Settings → Branding**.

| Setting | Default | What it does |
|---|---|---|
| Logo | TypstDrive logo | Shown in the top bar, on sign-in pages and in the browser tab. It is cropped to a square. **Use default logo** removes yours. |
| Site name | TypstDrive | Replaces the name everywhere. Up to 40 characters. |
| Tagline | A collaborative Typst editor and document manager. | Shown when the address is shared in chats and social media. Up to 120 characters. |
| Accent color | Theme color | One color for buttons and highlights for everyone. Leave it on the theme color to follow each person's chosen theme. |
| Sign-in message | Empty | A short note on the sign-in page, such as who to contact for an account. Up to 300 characters. |

**Use defaults** puts everything back.

While any of these differ from the defaults, a small "Powered by TypstDrive" link is shown in the corner of each page to credit the project.

People still choose their own color theme and dark or light mode in [their settings](../guide/settings.md#appearance). New browsers start with the Cerberus theme in dark mode.
