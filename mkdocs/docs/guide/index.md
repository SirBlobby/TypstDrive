# User Guide

This guide explains everything you can do in TypstDrive, one topic at a time. You do not need to read it in order.

| Page | What it covers |
|---|---|
| [Your drive](drive.md) | Folders, colors, search filters, stars, duplicating, exporting, selecting several items, the trash, uploads, downloads and importing files. |
| [Writing in the editor](editor.md) | The toolbar, view modes, inserting images and tables, find and replace, spell checking and keyboard shortcuts. |
| [Preview and export](preview-and-export.md) | The live preview, downloading PDFs, HTML pages and images from the editor or the drive, printing and converting to other formats. |
| [Working together](collaboration.md) | Editing at the same time, comments, suggestions and version history. |
| [Presenting](presenting.md) | Showing your document as full-screen slides and drawing on them. |
| [Projects](projects.md) | Documents made of many files, such as books, theses and templates. |
| [Templates](templates.md) | Starting a document or project from a Typst Universe template. |
| [LaTeX documents](latex.md) | Writing and previewing basic LaTeX, and what is supported. |
| [Packages](packages.md) | Sharing reusable templates and code with everyone on your server. |
| [Fonts and images](fonts-and-images.md) | Uploading your own fonts and pictures and using them in documents. |
| [Citations](citations.md) | Adding references by DOI, arXiv, PubMed or Semantic Scholar ID and syncing Zotero into bibliography files. |
| [Git sync](git.md) | Linking a project to a Git repository, pulling changes and pushing your own as commits. |
| [Sharing](sharing.md) | Who can see and change your work, share links and handing over ownership. |
| [Team spaces](teams.md) | Shared drives that belong to a group. |
| [Your settings](settings.md) | Your profile, sign-in, appearance and your own color themes, editor preferences, API keys and devices. |
| [Typst Desktop](desktop.md) | The desktop app that keeps your documents on your computer. |
