# Your first document

This page takes you from a new account to a finished, shared PDF.

## 1. Sign in

Open the address of your TypstDrive server in a browser. If you do not have an account yet, choose **Sign up**. Depending on how the server is set up, you may also see buttons to sign in with Google, GitHub or your organization, or an option to get a sign-in code by email.

!!! tip "Running your own server?"
    The very first person to open a new TypstDrive server creates the administrator account on a setup page. See [Install with Docker](../self-hosting/install.md).

## 2. Create a document

You land in your **drive**. Choose **New document** in the top right. A new document opens in the editor.

Choose **File → Rename** to give it a name.

## 3. Write something

Type on the left. The preview on the right updates as you type. Try this:

```typst
= My first document

Hello! This is *bold*, this is _italic_ and this is `code`.

== A list

- Apples
- Pears
- Plums

$ a^2 + b^2 = c^2 $
```

The toolbar above the editor has buttons for headings, bold, italic, lists, math and more, so you do not need to remember the syntax. New to Typst? Read [A short Typst primer](typst-primer.md).

Your work saves automatically. There is no save button to remember.

## 4. Share it

Choose **Share** in the top right. Type someone's email and pick what they can do:

- **Editor** can change the document.
- **Suggester** can propose changes for you to accept.
- **Viewer** can only read it.

You can also turn on a link that anyone can open. See [Sharing](../guide/sharing.md).

## 5. Export it

Choose the **Print or export** button in the top right, or open the **File** menu, and pick the PDF. The file downloads straight away. The same places offer PNG and SVG images, printing, and Word, Markdown, LaTeX or HTML. See [Preview and export](../guide/preview-and-export.md).
